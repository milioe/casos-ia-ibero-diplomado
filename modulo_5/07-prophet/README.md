# 07 - Prophet acciones

## Windows

1. `python -m venv .venv-07-prophet`
2. `.venv-07-prophet\Scripts\activate`
3. `pip install -r modulo_5/07-prophet/requirements.txt`
4. `jupyter notebook modulo_5/07-prophet/07_prophet_acciones.ipynb`

## Mac

1. `python3 -m venv .venv-07-prophet`
2. `source .venv-07-prophet/bin/activate`
3. `pip install -r modulo_5/07-prophet/requirements.txt`
4. `jupyter notebook modulo_5/07-prophet/07_prophet_acciones.ipynb`
