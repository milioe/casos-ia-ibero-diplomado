# 01 - LLMs con Gemini

## Clave API (antes del notebook)

1. Copia `modulo_5/01-llms/.env.example` -> `modulo_5/01-llms/.env`
2. Pon tu `GOOGLE_API_KEY` en `.env` -> [aistudio.google.com/apikey](https://aistudio.google.com/apikey)

## Windows

1. `python -m venv .venv-01-llms`
2. `.venv-01-llms\Scripts\activate`
3. `pip install -r modulo_5/01-llms/requirements.txt`
4. `jupyter notebook modulo_5/01-llms/01_LLMs.ipynb`

## Mac

1. `python3 -m venv .venv-01-llms`
2. `source .venv-01-llms/bin/activate`
3. `pip install -r modulo_5/01-llms/requirements.txt`
4. `jupyter notebook modulo_5/01-llms/01_LLMs.ipynb`
